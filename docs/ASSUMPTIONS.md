# Assumptions & Trade-offs

A running log. Every ambiguous requirement we resolved, and every shortcut we took, lives here
with the reasoning. Code shortcuts are also tagged `# SCALE-DEBT:` at the call site.

## Product & scope

| # | Assumption | Why |
|---|---|---|
| A1 | The fictional company is Commercial Bank; all sample documents are synthetic and generated by `scripts/generate_mock_data.py`. | No real data may be used. Generation makes the corpus reproducible. |
| A2 | "Last year" in the canonical RLM query means the trailing 12 months from today, not the previous calendar year. | This matches how an operations lead would phrase it. The planner shows the resolved date window in the Python plan, so the interpretation is visible. |
| A3 | Offline mode (`LLM_PROVIDER=none`) is a supported degraded mode, not the primary experience. | See ADR-0001. |

## Security & RBAC

| # | Assumption | Why |
|---|---|---|
| S1 | Document access levels are ordered `public < internal < confidential < restricted`. Clearance by role: Viewer → public, internal; Analyst → + confidential; Administrator → + restricted. | CLAUDE.md defines tool permissions per role but not document clearance. A strict ordering is the common bank classification model. |
| S2 | Auth uses Option A: hardcoded demo users with PBKDF2 password hashes, issuing HS256 JWTs. The role is re-resolved from the user directory on every request; the token's role claim is never trusted on its own. | Proves server-side RBAC without the operational weight of Keycloak. Swapping to OIDC only changes `auth/`. |

## Scalability debt

| # | Shortcut | Path to scale |
|---|---|---|
| D1 | Without `REDIS_URL`, the rate limiter, checkpointer and long-term memory are per-process. | Set `REDIS_URL` (Docker Compose does). `APP_ENV=production` refuses to start without it. |
